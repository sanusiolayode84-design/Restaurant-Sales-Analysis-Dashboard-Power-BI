# 🍽️ Restaurant Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing restaurant sales data using Microsoft Power BI to uncover valuable business insights, monitor key performance indicators (KPIs), and understand customer purchasing behavior.

The interactive dashboard provides a comprehensive overview of restaurant performance, sales trends, customer activity, delivery time, and payment preferences.

The goal is to help restaurant management make informed, data-driven business decisions.

## 🎯 Project Objectives

- Analyze overall restaurant sales performance.
- Identify restaurants with the highest number of orders.
- Understand customer ordering patterns.
- Analyze sales performance across different cuisines.
- Evaluate restaurant delivery performance.
- Understand customer ratings and satisfaction.
- Identify popular payment methods.
- Compare orders across different zones.

## 📈 Dashboard Insights

The dashboard contains several interactive visualizations:

1. **Restaurant Performance:** Identifies restaurants receiving the highest number of orders.
2. **Customer Analysis:** Highlights customers with the most orders.
3. **Orders by Time of Day:** Compares afternoon, night, morning, and evening orders.
4. **Cuisine Analysis:** Examines item sales across different cuisines.
5. **Zone Analysis:** Shows order distribution across restaurant zones.
6. **Payment Analysis:** Compares card and cash payment preferences.
